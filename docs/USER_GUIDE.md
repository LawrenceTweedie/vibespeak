## Getting Started

VibeSpeak is a real-time communication platform that allows you to:
- Make video and audio calls
- Share your screen
- Create private or public rooms
- Communicate with multiple participants

### System Requirements

**Web Browser:**
- Chrome 90+ (recommended)
- Firefox 88+
- Safari 14+
- Edge 90+

**Desktop App:**
- Windows 10/11
- macOS 10.13+
- Linux (Ubuntu 18.04+, Fedora 32+)

**Hardware:**
- Webcam (optional, for video)
- Microphone (for audio)
- Speakers or headphones
- Stable internet connection (minimum 2 Mbps)

## Creating an Account

### Registration

1. Visit the VibeSpeak website or open the desktop app
2. Click on the **Register** tab
3. Fill in the registration form:
   - **Username**: Choose a unique username (3-20 characters)
   - **Email**: Enter your email address
   - **Password**: Create a secure password (minimum 8 characters)
   - **Display Name**: Optional - this is how others will see you
4. Click **Register**

### Login

1. Enter your username or email
2. Enter your password
3. Click **Login**

**Demo Account:**
For testing purposes, you can use:
- Username: `demo`
- Password: `password`

## Joining Rooms

### From the Home Screen

1. After logging in, you'll see a list of available rooms
2. Click on any room to see details:
   - Room name
   - Description
   - Current participants
   - Room code
3. Click on a room card to join

### Using a Room Code

1. From the home screen, look for "Join by Code" option
2. Enter the 8-character room code
3. If the room is private, enter the password
4. Click **Join**

### Room Types

**Public Rooms:**
- Visible to all users
- Anyone can join without a password
- Great for community meetings

**Private Rooms:**
- Only visible to invited users
- Require a password to join
- Ideal for private conversations

## Creating Rooms

### Step by Step

1. From the home screen, click **+ Create Room**
2. Fill in the room details:
   - **Room Name**: Give your room a descriptive name
   - **Description**: Optional - describe the purpose of the room
   - **Max Participants**: Set the maximum number of participants (2-50)
   - **Public Room**: Check this box to make the room public
   - **Password**: If private, set a password (optional)
3. Click **Create**

### Room Codes

When you create a room, you'll receive a unique **room code** (e.g., `A8K9X2Z1`).
Share this code with others to invite them to your room.

## In-Room Features

### Interface Overview

When you enter a room, you'll see:
- **Header**: Room name, room code, and participant count
- **Video Grid**: Video feeds from all participants
- **Footer**: Media controls

### Media Controls

#### Microphone Control
- **Icon**: 🎤 (enabled) / 🔇 (muted)
- Click to toggle your microphone on/off
- Your microphone is **ON** by default when joining

#### Camera Control
- **Icon**: 📹 (enabled) / 📷 (disabled)
- Click to toggle your camera on/off
- Your camera is **OFF** by default when joining
- First-time use will prompt for camera permission

#### Screen Share
- **Icon**: 🖥️ (sharing) / 📺 (not sharing)
- Click to start/stop screen sharing
- You'll be prompted to select which screen or window to share
- Options:
  - **Entire Screen**: Share everything on your screen
  - **Window**: Share a specific application window
  - **Browser Tab**: Share a specific browser tab (web only)

#### Leave Room
- **Icon**: 📞 (red)
- Click to leave the room and return to the home screen

### Video Grid

The video grid automatically adjusts based on the number of participants:
- **1-2 participants**: Full screen layout
- **3-4 participants**: 2x2 grid
- **5-9 participants**: 3x3 grid
- **10+ participants**: Scrollable grid

**Your Video:**
- Indicated by "You" label
- Has a blue border
- Always visible in the grid

**Other Participants:**
- Labeled with their display name or username
- Shows their media state (audio/video icons)

### Permissions

When you first join a room, your browser will request permissions:

1. **Microphone Permission**: Required for audio
2. **Camera Permission**: Required for video (optional)
3. **Screen Share Permission**: Required when sharing screen (optional)

Click **Allow** to grant permissions.

## Desktop Application

### Installation

**Windows:**
1. Download `VibeSpeak Setup.exe`
2. Run the installer
3. Follow the installation wizard
4. Launch VibeSpeak from the Start menu

**macOS:**
1. Download `VibeSpeak.dmg`
2. Open the DMG file
3. Drag VibeSpeak to Applications folder
4. Launch from Applications

**Linux:**
1. Download `VibeSpeak.AppImage` or `.deb` package
2. For AppImage:
   ```bash
   chmod +x VibeSpeak.AppImage
   ./VibeSpeak.AppImage
   ```
3. For .deb:
   ```bash
   sudo dpkg -i vibespeak.deb
   ```

### Desktop vs Web

**Both versions offer:**
- Same features
- Same user interface
- Synchronized accounts

## Tips and Best Practices

### Audio Quality

1. **Use headphones** to prevent echo and feedback
2. **Position microphone** 6-12 inches from your mouth
3. **Reduce background noise**:
   - Close windows
   - Turn off fans/AC when possible
   - Use a quiet room

### Video Quality

1. **Good lighting**:
   - Face a window or light source
   - Avoid backlighting
   - Use desk lamp if needed

2. **Camera position**:
   - Place camera at eye level
   - Ensure your face is centered
   - Leave space above your head in frame

3. **Background**:
   - Use a clean, professional background
   - Avoid clutter
   - Ensure privacy (no sensitive information visible)

### Screen Sharing

1. **Prepare in advance**:
   - Close unnecessary windows
   - Hide personal information
   - Organize desktop icons

2. **Share specific windows** instead of entire screen when possible

3. **Stop sharing** when done to save bandwidth

### Internet Connection

**Recommended speeds:**
- Audio only: 1 Mbps
- Video (720p): 2.5 Mbps
- Video (1080p): 4 Mbps
- Screen sharing: +1 Mbps

**Tips:**
- Use wired Ethernet connection when possible
- Close bandwidth-heavy applications
- Ensure other devices aren't consuming bandwidth

### Room Management

**As Room Owner:**
1. Share room code via secure channels only
2. Use passwords for private rooms
3. Set appropriate participant limits
4. Monitor participants
5. Close room when meeting ends

**Best Practices:**
1. Mute when not speaking
2. Test audio/video before important calls
3. Use screen share for presentations
4. Respect others' privacy

## FAQ

### How many people can join a room?

You can set the maximum participants when creating a room, from 2 to 50 participants. The actual optimal number depends on your internet connection and hardware.

### Is VibeSpeak free?

Check with your administrator for pricing information.

### Can I use VibeSpeak on mobile?

Currently, VibeSpeak is optimized for desktop browsers and desktop applications. Mobile browser support may be limited.

### Why can't others hear me?

1. Check if your microphone is muted (🔇 icon)
2. Verify browser has microphone permission
3. Check system microphone settings
4. Try refreshing the page
5. Test microphone with other apps

### Why can't I see video?

1. Check if camera is disabled (📷 icon)
2. Verify browser has camera permission
3. Ensure no other app is using the camera
4. Check system camera settings
5. Try refreshing the page

### Why is screen sharing not working?

1. Ensure you granted screen share permission
2. Try a different screen/window
3. Update your browser
4. Restart the browser
5. Check system privacy settings

### How do I report issues?

Contact your system administrator or visit the support page.

### Can I record meetings?

Recording features depend on your administrator's configuration. Use your operating system's screen recording features as an alternative.

### What about privacy and security?

- All communications use WebRTC with encryption
- Rooms can be password protected
- No conversation data is stored permanently on the server
- Check your organization's privacy policy for details

### How do I change my display name?

You can set your display name during registration. To change it later, contact your administrator or re-register.

### Can I use VibeSpeak without a camera?

Yes! You can participate in audio-only mode. Just keep your camera disabled.

### What is the difference between muting and turning off video?

- **Muting**: Disables audio transmission but keeps your microphone active locally
- **Turning off video**: Stops camera capture and transmission entirely

### How much bandwidth does VibeSpeak use?

Approximate usage per participant:
- Audio only: ~50-100 KB/s
- Video (720p): ~500-1000 KB/s
- Video (1080p): ~1-2 MB/s
- Screen sharing: +200-500 KB/s

### Can I join multiple rooms at once?

No, you can only be in one room at a time. You must leave your current room before joining another.

### What happens if I lose internet connection?

If you lose connection:
1. You'll be automatically removed from the room
2. Other participants will be notified
3. Reconnect and rejoin the room when connection is restored

### How do I get the best quality?

1. Use wired internet connection
2. Close other bandwidth-heavy applications
3. Use a modern browser (Chrome recommended)
4. Ensure good lighting for video
5. Use quality microphone/headphones

## Troubleshooting

### Poor Video Quality

1. Check internet speed
2. Reduce number of participants
3. Lower video quality in settings
4. Close other applications

### Echo or Feedback

1. Use headphones
2. Ask others to mute when not speaking
3. Reduce speaker volume
4. Check for multiple audio outputs

### Lag or Delay

1. Check internet connection
2. Close unnecessary applications
3. Restart browser/application
4. Move closer to WiFi router
